# Changelog

## 0.1.2 - 2026-11-01

- Replaced the generic flat meter frame with Blizzard tooltip-frame artwork.
- Standardized the title, footer, border, and background around stock WoW fonts and colors.
- Kept the class-colored DPS bars and all meter behavior unchanged.

## 0.1.1 - 2026-11-01

- Added shared `/foreverdebug` diagnostics for launch-day compatibility testing.

## 0.1.0 - 2026-11-01

Initial pre-launch build.

- Simple current-fight and overall DPS ranking views.
- Class-colored bars with the local player highlighted.
- Live `YOU: #x / y` placement.
- Post-combat DPS and percentage-of-leader summary.
- Top-10 display that keeps the local player visible when ranked below 10th.
- Movable, lockable, scalable window.
- All automatic chat output disabled by default.
- Optional personal summary, party/raid/instance announcement, and manual report commands.
- Opt-in local debug status for launch-day troubleshooting.
- Standard and `_Camelot.toc` manifests for Forever compatibility.
